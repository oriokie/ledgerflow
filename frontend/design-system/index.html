Foundations · v1

Money, set like a ledger.

Every amount in LedgerFlow renders in a duospace ledger face — tabular, sign-explicit, cents de-emphasized but never hidden. Earning is verdant. Spending is ink, because spending is normal life. Carmine is reserved for things that are actually wrong.
